# 🌳 شجره‌نامه (Family Tree)

اپلیکیشن موبایلی که با **Flutter** و **Dart** ساخته شده و شجره‌نامه یک خاندان
را به‌صورت زیبا، ساده و تعاملی نمایش می‌دهد. رابط کاربری کاملاً فارسی و
راست‌به‌چپ (RTL) است.

> نسخه‌ی فعلی یک اپ **ارائه‌ی اطلاعات** است — کاربر می‌تواند شجره‌نامه‌ی
> خاندان پیش‌فرض («خاندان رضایی») را مرور و در آن جستجو کند. امکان افزودن،
> ویرایش یا حذف اطلاعات توسط کاربر در این نسخه وجود ندارد.

---

## ✨ قابلیت‌ها

- نمایش سلسله‌مراتبی و **مرحله‌ای** شجره‌نامه (نسل به نسل، نه یک درخت شلوغ)
- عنوان هر صفحه، نام واقعی زوج/فرد همان نسل است (نه «نسل ۱»، «نسل ۲»)
- **Breadcrumb** افقی و قابل‌اسکرول برای دیدن مسیر فعلی در شجره‌نامه
- پشتیبانی کامل از **افراد مشترک بین چند شاخه** (مثلاً عروس/داماد خانواده)
  از طریق یک `Person ID` واحد — بدون تکرار اطلاعات
- دکمه‌ی «مشاهده در خانواده اصلی ↗» برای پرش به خانواده‌ای که فرد در آن
  متولد شده
- صفحه‌ی اطلاعات کامل هر فرد (همسر، والدین، فرزندان)
- جستجوی فرد بر اساس نام، نام خانوادگی یا نام کامل
- **نمای درختی** (Tree View) با قابلیت Zoom/Pan برای دید کلی (`InteractiveViewer`)
- طراحی مدرن، ساده و خلوت با فونت فارسی **Vazirmatn** و Material 3

## 🧬 فرمت داده JSON

داده در `assets/data/family.json` نگه‌داری می‌شود. ساختار Entity-محور است:
هر فرد یک بار و فقط یک بار در آرایه‌ی `people` تعریف می‌شود و تمام روابط
(ازدواج، فرزندی) صرفاً با اشاره به `id` او در `families` بیان می‌شوند. این
یعنی یک فرد می‌تواند هم‌زمان فرزند یک خانواده و همسر خانواده‌ای دیگر باشد،
بدون این‌که اطلاعاتش دو بار ذخیره شود.

```jsonc
{
  "title": "خاندان رضایی",
  "rootFamilyId": "family_001",

  "people": [
    { "id": "p001", "firstName": "احمد", "lastName": "رضایی", "birthYear": 1300 }
    // ...
  ],

  "families": {
    "family_001": {
      "husbandId": "p001",
      "wifeId": "p002",          // اختیاری
      "childrenIds": ["p003", "p004"]
    }
  }
}
```

- `birthYear` فقط **سال تولد** است (تقویم شمسی)؛ ماه و روز ذخیره نمی‌شود.
- نام خانوادگی هر فرد کاملاً مستقل است — پس از ازدواج تغییر نمی‌کند.
- `rootFamilyId` نقطه‌ی شروع نمایش شجره‌نامه (پدرجد/مادرجد اصلی) است.

### ➕ نحوه اضافه کردن اطلاعات خاندان

1. برای هر فرد جدید یک شیء در `people` با یک `id` یکتا (مثلاً `p017`)
   اضافه کنید.
2. برای هر ازدواج/خانواده جدید، یک کلید جدید در `families` بسازید و
   `husbandId` / `wifeId` / `childrenIds` را با همان `id`های تعریف‌شده در
   `people` پر کنید.
3. اگر فردی همسرش را از خانواده‌ی دیگری گرفته، به‌جای تعریف دوباره‌ی او، از
   همان `id` موجودش استفاده کنید — این همان چیزی است که امکان «مشاهده در
   خانواده اصلی» را فراهم می‌کند.
4. فایل را ذخیره کرده و `flutter run` را دوباره اجرا کنید.

> در آینده معماری این پروژه اجازه می‌دهد چند خاندان مختلف (چند فایل JSON یا
> منبع داده) بدون بازنویسی UI اضافه شوند.
